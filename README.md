# 🍄 Шерво Кликер

Браузерный кликер в стиле Minecraft: кликай по грибу, копи чачу, прокачивайся, перерождайся и открывай новые механики.

## 🎮 Играть

👉 **[Открыть игру](https://koshak-chernobil.github.io/Sherwo-Clicker/)**

## ✨ Возможности

- 🍄 **Кликер** — классический клик по грибу с частицами и всплывающими цифрами
- 🏭 **Магазин** — кирки, заводы, артефакты и зелья силы
- 🌳 **Дерево улучшений** — 16+ узлов с ветвлением, покупай по одному или полностью
- 🧠 **Дерево навыков** — прокачка за очки престижа
- 🔄 **Перерождение** — сброс прогресса за бонусы и очки престижа
- 📜 **Квесты** — обычные, ежедневные, еженедельные и избранные
- 🏆 **Достижения** — 120 штук, от «Кликер 1» до «Абсолют»
- ⛏️ **Шахта** — мини-игра на поиск грибочков
- 🎣 **Ловля грибов** — кликай по летающим грибам
- 🤖 **Автокликер** — открывается с 3 перерождений
- 🧪 **Авто-буст** — автоматическая покупка зелий силы
- 💰 **Оффлайн заработок** — чача и опыт копятся, пока ты не в игре (до 7 дней)
- 👤 **Профиль** — аватар, статистика, чача в час
- 🛡️ **Админ-консоль** — редактирование чужих аккаунтов (только для админа)
- 🎨 **Фоны** — 4 встроенных + своя загрузка
- 🎵 **Музыка** — своя YouTube-ссылка
- 🌐 **Аккаунты** — регистрация и вход через Firebase
- 🎮 **Режимы** — обычный, хардкор, разработчик

## 🕹️ Управление

- **ЛКМ** — клик по грибу
- **Колёсико** — прокрутка магазина и зума дерева улучшений
- **Shift + ЛКМ** — тащить дерево улучшений
- **Esc** — закрыть модалку
